vorb-ui turns a normalized voice signal into an expressive interface. Use it as a passive status
visual, let it own the call control, or connect it to a provider through an adapter.

## What it solves

- One stable component API across five visual themes.
- A consistent `idle → connecting → listening → thinking → speaking` state model.
- Input and output volume that produce real visual response.
- Optional lifecycle control with predictable placement and styling.
- Provider adapters that keep SDK-specific events out of your UI.

Continue with the [quick start](/docs/quick-start), or open the
[playground](/playground) to inspect every option live.
